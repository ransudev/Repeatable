## Download

- Grab the latest release and run `Repeatable.exe`

## Features

- Record mouse and keyboard actions
- Replay macros with adjustable speed
- Loop playback
- Built-in macro library
- Compact and expanded UI modes
- Global hotkey customization

## Usage

1. Open `Repeatable.exe`
2. Click **Record**
3. Perform the actions you want to save
4. Click **Stop**
5. Click **Play** to replay the macro

## Hotkeys

| Action | Default |
| --- | --- |
| Record | F8 |
| Play / Stop | F10 |
| Pause | F11 |
| Emergency Stop | F12 |

## UI modes

- **Compact mode** is a small always-on-top control bar
- **Expanded mode** shows the macro library, timeline, and settings
